File layout (ELF 32/64 coexist in same file via e_ident[EI_CLASS]):
- e_ident[0..3]: \x7F E L F (4 bytes, fixed)
- e_ident[4]: EI_CLASS (1 byte: 1=32-bit, 2=64-bit)
- e_ident[5]: EI_DATA (1 byte: 1=little, 2=big)
- e_ident[6]: EI_VERSION (1 byte, must be 1)
- e_ident[7..15]: padding (9 bytes, fixed)
- e_type (2 bytes, BE/LE per EI_DATA): ET_NONE=0, ET_REL=1, ET_EXEC=2, ET_DYN=3, ET_CORE=4
- e_machine (2 bytes, BE/LE): EM_NONE=0, EM_X86_64=62, EM_386=3, EM_ARM=40, EM_AARCH64=183, etc.
- e_version (4 bytes, BE/LE): must be 1
- e_entry (4/8 bytes, BE/LE): entry virtual address
- e_phoff (4/8 bytes, BE/LE): program header table offset
- e_shoff (4/8 bytes, BE/LE): section header table offset
- e_flags (4 bytes, BE/LE): processor-specific
- e_ehsize (2 bytes, BE/LE): ELF header size (52 for 32-bit, 64 for 64-bit)
- e_phentsize (2 bytes, BE/LE): program header entry size (32 or 56)
- e_phnum (2 bytes, BE/LE): program header entry count
- e_shentsize (2 bytes, BE/LE): section header entry size (40)
- e_shnum (2 bytes, BE/LE): section header entry count
- e_shstrndx (2 bytes, BE/LE): section header string table index

Program header table (if e_phnum > 0):
- phdr ::= p_type (4 bytes, BE/LE) p_flags (4 bytes, BE/LE) p_offset (4/8) p_vaddr (4/8) p_paddr (4/8) p_filesz (4/8) p_memsz (4/8) p_align (4/8)
- p_type: PT_NULL=0, PT_LOAD=1, PT_DYNAMIC=2, PT_INTERP=3, PT_NOTE=4, PT_SHLIB=5, PT_PHDR=6, PT_TLS=7, PT_GNU_EH_FRAME=0x6474e550, PT_GNU_STACK=0x6474e551, PT_GNU_RELRO=0x6474e552
- p_flags (32-bit): PF_X=1, PF_W=2, PF_R=4; (64-bit): same bits in lower 3 bytes

Section header table (if e_shnum > 0):
- shdr ::= sh_name (4 bytes, BE/LE) sh_type (4) sh_flags (4/8) sh_addr (4/8) sh_offset (4/8) sh_size (4/8) sh_link (4) sh_info (4) sh_addralign (4/8) sh_entsize (4/8)
- sh_type: SHT_NULL=0, SHT_PROGBITS=1, SHT_SYMTAB=2, SHT_STRTAB=3, SHT_RELA=4, SHT_HASH=5, SHT_DYNAMIC=6, SHT_NOTE=7, SHT_NOBITS=8, SHT_REL=9, SHT_SHLIB=10, SHT_DYNSYM=11, SHT_INIT_ARRAY=14, SHT_FINI_ARRAY=15, SHT_PREINIT_ARRAY=16, SHT_GROUP=17, SHT_SYMTAB_SHNDX=18, SHT_GNU_ATTRIBUTES=0x6ffffff5, SHT_GNU_HASH=0x6ffffff6, SHT_GNU_LIBLIST=0x6ffffff7, SHT_CHECKSUM=0x6ffffff8, SHT_GNU_verdef=0x6ffffffd, SHT_GNU_verneed=0x6ffffffe, SHT_GNU_versym=0x6fffffff
- sh_flags (32-bit): SHF_WRITE=1, SHF_ALLOC=2, SHF_EXECINSTR=4; (64-bit): same bits in lower 3 bytes plus SHF_COMPRESSED=0x80000000 in high word

String tables (referenced by sh_name): null-terminated ASCII strings

Symbol tables (SHT_SYMTAB/SHT_DYNSYM):
- 32-bit: st_name (4) st_value (4) st_size (4) st_info (1) st_other (1) st_shndx (2)
- 64-bit: st_name (4) st_info (1) st_other (1) st_shndx (2) st_value (8) st_size (8)
- st_info: 4-bit type (STT_NOTYPE=0, STT_OBJECT=1, STT_FUNC=2, STT_SECTION=3, STT_FILE=4, STT_COMMON=5, STT_TLS=6) + 4-bit binding (STB_LOCAL=0, STB_GLOBAL=1, STB_WEAK=2)
- st_other: visibility (STV_DEFAULT=0, STV_INTERNAL=1, STV_HIDDEN=2, STV_PROTECTED=3)

Relocation sections (SHT_REL/SHT_RELA):
- REL: r_offset (4/8) r_info (4/8) — no addend
- RELA: r_offset (4/8) r_info (4/8) r_addend (4/8)
- r_info: 32-bit: 8-bit type + 24-bit symbol index; 64-bit: 32-bit type + 32-bit symbol index

Dynamic section (SHT_DYNAMIC):
- d_tag (4/8, BE/LE): DT_NULL=0, DT_NEEDED=1, DT_PLTRELSZ=2, DT_PLTGOT=3, DT_HASH=4, DT_STRTAB=5, DT_SYMTAB=6, DT_RELA=7, DT_RELASZ=8, DT_RELAENT=9, DT_STRSZ=10, DT_SYMENT=11, DT_INIT=12, DT_FINI=13, DT_SONAME=14, DT_RPATH=15, DT_SYMBOLIC=16, DT_TEXTREL=17, DT_DATAREL=18, DT_DATAREL=19, DT_ENCODING=20, DT_PREINIT_ARRAY=21, DT_PREINIT_ARRAYSZ=22, DT_SYMTAB_SHNDX=23, DT_GNU_HASH=0x6ffffef5, DT_GNU_CONFLICT=0x6ffffef8, DT_GNU_LIBLIST=0x6ffffef9, DT_CHECKSUM=0x6ffffefa, DT_PLTPADDR=0x6ffffefb, DT_MOVEENT=0x6ffffefc, DT_MOVESZ=0x6ffffefd, DT_FEATURE=0x6ffffff0, DT_POSFLAG_1=0x6ffffff1, DT_SYMINSZ=0x6ffffff2, DT_SYMINENT=0x6ffffff3, DT_GNU_RELRO=0x6ffffffa, DT_GNU_EH_FRAME=0x6474e550
- d_un: either d_val (integer) or d_ptr (address)

Version sections (SHT_GNU_verdef/SHT_GNU_verneed/SHT_GNU_versym):
- verdef: vd_version (2) vd_flags (2) vd_ndx (2) vd_cnt (2) vd_hash (4) vd_aux (4) vd_next (4)
- verdaux: vda_name (4) vda_next (4)
- verneed: vn_version (2) vn_cnt (2) vn_file (4) vn_aux (4) vn_next (4)
- vernaux: vna_hash (4) vna_flags (2) vna_other (2) vna_name (4) vna_next (4)
- versym: 2-byte entries indexing version table

Mutator strategy:
- Keep e_ident[0..3] and e_ident[4..15] framing intact
- Target e_type, e_machine, e_version, e_flags, e_phnum, e_shnum, e_shstrndx for overflow/edge values
- Flip e_class (32/64) only when e_ident[4] is mutated; ensure header size fields (e_ehsize, e_phentsize, e_shentsize) match the class
- Mutate p_type/p_flags in program headers; ensure p_offset + p_filesz <= file size and p_vaddr/p_paddr alignment per p_align
- Mutate sh_type/sh_flags in section headers; ensure sh_offset + sh_size <= file size and sh_addr alignment per sh_addralign
- Mutate st_info binding/type and st_other visibility in symbol tables; ensure st_shndx references valid section indices
- Mutate d_tag and d_un in dynamic section; ensure referenced string offsets are within strtab bounds
- DO recompute section header sh_size for modified sections; DO NOT recompute ELF-level CRCs (none exist); DO recompute internal hashes only if mutated (e.g., version hashes)
PER-MUTATION COST: keep each mutation tiny — at most ~16 bytes of write. AFL's havoc/cmplog will compose larger runs across iterations.
